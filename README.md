---

## 🎯 Internship Objectives

The major objectives of the internship were:

* Build a strong foundation in Machine Learning.
* Learn Machine Learning workflows using **Amazon SageMaker**.
* Understand data splitting and model training using **XGBoost**.
* Learn the fundamentals of **Natural Language Processing (NLP)**.
* Explore text processing and sentiment analysis.
* Understand information extraction and topic modeling.
* Learn Generative AI concepts and applications.
* Understand **Foundation Models** and Prompt Engineering.
* Develop awareness of Responsible AI, including security, governance, and compliance.
